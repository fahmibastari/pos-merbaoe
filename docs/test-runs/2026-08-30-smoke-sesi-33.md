## Temuan

### QA-001 — F2 Tunai memfokuskan Diskon, bukan Uang Diterima · Medium

- Reproduksi: tambah Americano → metode Tunai → tekan F2.
- Aktual: active element adalah input `discountPreview`.
- Harapan: input `cashReceivedPreview` dipilih.
- Bukti source: `cashReceivedInputRef` terpasang pada input Diskon, sedangkan input Uang
  Diterima tidak mempunyai ref.
- Dampak: shortcut utama kasir mengarahkan fokus ke kontrol yang salah; transaksi tetap
  bisa dilakukan dengan pointer/Tab.

### QA-002 — Pengumuman restore keranjang berpotensi dibaca dua kali · Low

- Reproduksi: simpan satu item di keranjang lalu reload.
- Aktual: pesan “Keranjang sebelumnya dipulihkan” muncul pada dua live region.
- Bukti source: pesan yang sama dikirim ke `cartNotice` (`Feedback role=status`) dan
  `keyboardAnnouncement` (`p role=status`).
- Dampak: pengguna screen reader berpotensi mendengar notifikasi ganda.

### QA-003 — Foto menu pertama memicu warning LCP development · Low

- Aktual: Next.js meminta gambar di atas fold memakai eager/priority loading.
- Dampak: tidak memblokir fungsi, tetapi dapat menurunkan LCP POS pada cold load.

### QA-004 — Instalasi `node_modules` semula mempunyai junction pnpm putus · High, dipulihkan lokal

- Fresh dev compile menemukan runtime `@prisma/client` dan `pg` tidak tersedia meski
  `pnpm list` melaporkannya terpasang.
- `node_modules` lama dipindahkan keluar workspace; instalasi frozen dari `pnpm-lock.yaml`
  direkonstruksi dari store lokal dan `prisma generate` berhasil.
- Wrapper pnpm Codex tetap mengembalikan `ERR_PNPM_IGNORED_BUILDS` karena kebijakan
  supply-chain lokal. Dev server dapat dijalankan langsung melalui binary Next.
- Fresh `/login` sekarang merespons 200; `/admin/dashboard` tanpa cookie merespons 307
  ke `/login`. Verifikasi browser terautentikasi menunggu refresh tab oleh pengguna.
