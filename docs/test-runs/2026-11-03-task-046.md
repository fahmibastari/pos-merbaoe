# TASK-046 — Sinkronisasi filter

Tanggal: 3 November 2026. Lingkungan: production build lokal, Chromium desktop,
database Supabase yang telah diaktifkan kembali. Git dan deployment dikelola pemilik.

## Perubahan

- `FilterForm` mengganti kontrol form berdasarkan parameter URL dan periode efektif.
  Tanggal, pencarian, dan dropdown tidak mempertahankan edit lama setelah navigasi.
- Reset/Bulan Ini membuang edit yang belum diterapkan, termasuk pada URL bawaan.
- Dashboard, Pembelian, Pengeluaran, Penjualan, Shift, Laporan Laba, Laporan Persediaan,
  dan Jejak Audit memakai komponen bersama. Kartu Stok memakai key form sesuai URL.
- Periode invalid pada laporan kembali ke periode efektif; pada daftar tanpa periode
  bawaan kontrol tanggal kembali kosong disertai pesan validasi.
- Fixture pagination menambah 21 audit milik akun E2E sementara, lalu dibersihkan melalui
  teardown. Timeout pembersihan fixture E2E diperbesar menjadi 30 detik agar rangkaian
  penghapusan tidak terpotong batas default 5 detik pada koneksi Supabase.
- Panduan cetak T-07 menambahkan pengecekan nilai kotak tanggal dan Back/Forward.

## Gate baseline yang masih terbuka

Lima kegagalan Node berupa masalah waktu transaksi: I-03/I-05/I-06 pada pembersihan fixture
yang melewati 5 detik, kategori saat memulai transaksi, serta throttle login saat memulai
transaksi. Satu kegagalan laporan membandingkan total `openingIn` seluruh database dengan
nilai fixture 1.000; hasil aktual 5.902.000 karena database kini berisi data demo.

Perubahan TASK-046 tidak mengubah query/perhitungan transaksi. Namun baseline penuh belum
dapat dinyatakan hijau. Perlu menjalankan integrasi pada database QA terpisah dan menata
timeout pembersihan fixture sebelum menandai task selesai menurut gate roadmap.

Tiga fixture TASK-035 yang tertinggal akibat rollback cleanup dibersihkan kembali dengan
ID/username/tanggal pembuatan yang diverifikasi. Data akun dan transaksi di luar fixture
tersebut tidak menjadi target pembersihan.
