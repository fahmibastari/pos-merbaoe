# PHASE 3 — VISUAL & USER INTERFACE AUDIT

Audit seluruh UI berdasarkan source code.

Evaluasi:

## Layout

- page structure;
- container width;
- grid;
- alignment;
- spacing;
- whitespace;
- density;
- hierarchy;
- responsive behavior.

## Color

- color tokens;
- semantic colors;
- contrast;
- consistency;
- destructive/success/warning states;
- dark/light mode jika tersedia.

## Typography

- font families;
- font sizes;
- weight;
- hierarchy;
- line-height;
- letter spacing;
- consistency.

## Component System

Cari apakah terdapat design system yang nyata.

Evaluasi:

- buttons;
- inputs;
- selects;
- dialogs;
- dropdowns;
- tables;
- cards;
- badges;
- tabs;
- navigation;
- forms;
- toast;
- tooltip;
- pagination;
- loading states;
- empty states;
- error states.

Cari:

- duplicated components;
- inconsistent variants;
- magic values;
- page-specific styling;
- inconsistent spacing;
- components yang terlalu spesifik;
- components yang terlalu generic.

## AI Slop Detection

Cari indikasi:

- overly rounded components tanpa alasan;
- excessive shadows;
- excessive gradients;
- excessive glassmorphism;
- arbitrary animations;
- decorative UI yang tidak membantu workflow;
- generic dashboard templates;
- unnecessary cards;
- too many icons;
- inconsistent visual language;
- excessive whitespace yang mengurangi information density;
- fake sophistication;
- UI yang terasa generik;
- visual hierarchy yang tidak mencerminkan prioritas bisnis.

Untuk POS, prioritaskan:

> speed, clarity, scanability, consistency, accuracy, and low cognitive load.
