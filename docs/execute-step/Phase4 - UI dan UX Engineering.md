# PHASE 4 — UX & UX ENGINEERING

Evaluasi alur pengguna.

Audit:

- navigation;
- information architecture;
- task completion;
- number of clicks;
- form efficiency;
- keyboard interaction;
- focus management;
- validation;
- feedback;
- loading state;
- error state;
- empty state;
- confirmation;
- destructive actions;
- undo/recovery;
- search;
- filtering;
- pagination;
- transaction flow.

Tentukan apakah UI mendukung workflow POS yang cepat.

Jangan hanya menilai estetika.

Pertanyaan utama:

> Apakah kasir dapat menyelesaikan pekerjaan secara cepat, jelas, dan dengan kemungkinan error serendah mungkin?
