# PHASE 5 — ACCESSIBILITY AUDIT

Audit berdasarkan prinsip WCAG yang relevan.

Periksa:

- semantic HTML;
- labels;
- keyboard navigation;
- focus state;
- focus trap;
- color contrast;
- aria;
- screen reader compatibility;
- button semantics;
- form semantics;
- error messaging;
- modal behavior;
- interactive states.

Jangan mengklaim compliance penuh apabila belum melakukan validasi yang memadai.

Gunakan istilah seperti:

> “Potential accessibility issue”

jika evidence belum cukup.
