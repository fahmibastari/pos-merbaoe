# PHASE 9 — TECHNICAL DEBT

Klasifikasikan technical debt:

### Critical Debt
Menghambat correctness/security/operasional.

### Structural Debt
Membuat pengembangan fitur baru semakin sulit.

### UX Debt
Membuat pengalaman pengguna tidak konsisten atau lambat.

### Visual Debt
Membuat UI tidak konsisten atau terlihat unfinished.

### Maintenance Debt
Membuat perubahan kecil membutuhkan perubahan di banyak tempat.

Untuk setiap debt:

- evidence;
- impact;
- severity;
- recommended solution;
- estimated complexity;
- priority.
